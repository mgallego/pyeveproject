# PyEveProject

> Temporary name. I haven't decided what to call this project yet, so for now it's known as **PyEveProject**.

> **Warning about AI-generated code:** only the frontend is developed with AI (agents, sub-agents, skills, etc.). Everything else is written by hand. I use AI for the frontend because it's not my strong point and I also want to show that I know how to use it.

A web application for personal use to manage my EVE Online characters and their finances.

## Motivation

I'm making the jump from PHP to Python and I want to refresh my knowledge and update myself by applying modern tools and technologies. To do this, I'm building a real, open source project that serves as a portfolio.

## What it is

EVE Online is a game that, to get the most out of it, practically forces you to keep a spreadsheet open next to you. Since I don't like Excel and EVE has a very well documented and complete REST API, I'm going to build this web application.

It will be an open source project in case anyone finds it useful, although it's more of a playground for technologies than a finished product.

## Goals and approach

- Build a project in Python using both the **standard library** and **modern libraries and frameworks**.
- Deploy it on **one or more servers**, with **CI/CD**, **monitoring** and **alerting**.
- Build it step by step, in my spare time, without rushing.
- The **frontend** will be developed with **AI** (agents, sub-agents, skills, etc.), as it's not my strong point and I also want to show that I know how to use it.
- **Everything else** will be written by hand, reading the documentation.

## Status

Early stage project. It will be built incrementally in my spare time.
